macOS app icon

1024 px canvas, 824 px body on a superellipse rather than a plain rounded rectangle, so it sits correctly beside system icons in the Dock. Photopipe.icns and Photopipe-Dark.icns are ready to drop into the bundle; the .iconset folder is there too if you would rather run iconutil yourself.

Menu bar

Two ways to ship this. The template route is one asset: photopipeTemplate.png is pure black on transparent, and the Template suffix tells AppKit to invert it to white in dark mode, in the menu-bar highlight state, and when the bar is tinted by the wallpaper. The explicit route is two assets, photopipe-menubar-light.png (black) and -dark.png (white), which you swap yourself — use this only if you need the accent to stay orange, since template images are forced monochrome.

// template — one asset, AppKit handles light/dark/highlight
let image = NSImage(named: "photopipeTemplate")!
image.isTemplate = true            // the filename already implies it; explicit is fine
statusItem.button?.image = image

// explicit — two assets, if you need to keep the accent colour
let name = NSApp.effectiveAppearance.bestMatch(from: [.aqua, .darkAqua]) == .darkAqua
    ? "photopipe-menubar-dark" : "photopipe-menubar-light"
statusItem.button?.image = NSImage(named: name)

Animated

Top row is photopipe-loop.svg, bottom is photopipe-intro.svg. The intro plays once and settles — app launch, page load. The loop runs every element on one shared 3.49 s cycle with an exit phase, so it repeats seamlessly and the elements cannot drift out of sync. Both are pure declarative CSS inside the SVG, so they animate in an <img> tag, and both honour prefers-reduced-motion.

Notes

  • Clear space — one slice-width (4 units on the 64 grid) on every side; double that around the lockup.
  • Minimum sizes — primary down to 28 px, small variant 16–24 px, lockup no smaller than 22 px mark height.
  • Dark mode — set color to white. Nothing else needs to change; the accent holds contrast on both surfaces.
  • Do not re-space the slices, swap the accent onto a slice, or add a second accent colour. The fade is the whole idea.
  • Wordmark — Inter, semibold "photo" and regular at 60% for "pipe", already outlined in the lockup files.
